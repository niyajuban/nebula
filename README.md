# 🌌 Nebula

> A hardware event project featuring a custom ESP32 CyberDeck with an OLED UI, sensors, Bluetooth audio, voice chatbot, and a web dashboard.

---

## 📦 What's Coming

| Layer | Description |
|---|---|
| `firmware/` | ESP32 firmware — OLED menu, BMP180, Pomodoro, voice chatbot, Bluetooth |
| `backend/` | Express server — `/ask` and `/transcribe` endpoints |
| `gemini/` | Gemini API microservice for the AI chatbot |
| `dashboard/` | React web dashboard for monitoring and control |
